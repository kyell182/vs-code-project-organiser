# Changelog

## 0.1.0

- Save projects and open them with one click.
- Virtual groups with drag and drop.
- Colored tags that can be created, renamed, recolored and deleted.
- Automatic and manual project status with colors.
- Sidebar views by group, tag and status; pinned projects.
- Quick switcher (`Ctrl+Alt+P`) and status bar item.
- Settings Sync support.
