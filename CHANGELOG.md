# Changelog

## 0.2.0

- Project board: kanban columns per status with drag and drop, search, colored chips, notes, project type and git branch.
- Custom statuses with their own color.
- A color per group.
- Custom colors for tags, groups and statuses via a real color picker, next to the theme-aware standard colors.
- Notes per project.

## 0.1.0

- Save projects and open them with one click.
- Virtual groups with drag and drop.
- Colored tags that can be created, renamed, recolored and deleted.
- Automatic and manual project status with colors.
- Sidebar views by group, tag and status; pinned projects.
- Quick switcher (`Ctrl+Alt+P`) and status bar item.
- Settings Sync support.
