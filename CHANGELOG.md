# Changelog

## 0.3.0

- To-dos per project: tick off, add, edit and delete in one list; progress and next steps on cards, books and tooltips.
- Notes are full markdown documents that open in an editor tab and are saved with Ctrl+S.
- Bookcase view on the project board (the default view): a shelf per status, a book per project in its own color with a bookmark ribbon per tag (more than three tags grouped into one ribbon) and a tooltip.
- Drag projects within a column or shelf to put them in your own order.
- Change Book Color… command.
- Opening a project always reuses the current window; Alt+click (board, bookcase) or the new-window button opens a new one.
- Richer sidebar tooltip with colored tags, relative "last opened" time and quick actions.
- Manage Tags… command.
- New README and docs/ARCHITECTURE.md with diagrams.

## 0.2.0

- Project board: kanban columns per status with drag and drop, search, colored chips, notes, project type and git branch.
- Custom statuses with their own color.
- A color per group.
- Custom colors for tags, groups and statuses via a real color picker, next to the theme-aware standard colors.
- Notes per project.

## 0.1.0

- Save projects and open them with one click.
- Virtual groups with drag and drop.
- Colored tags that can be created, renamed, recolored and deleted.
- Automatic and manual project status with colors.
- Sidebar views by group, tag and status; pinned projects.
- Quick switcher (`Ctrl+Alt+P`) and status bar item.
- Settings Sync support.
